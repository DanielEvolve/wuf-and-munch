# Wuf & Munch

Tienda en línea de snacks y accesorios naturales para mascotas, construida sobre Shopify con personalización en HTML, CSS y JavaScript. Arquitectura lista para integrar pasarelas de pago como Stripe o PayPal.

🔗 [Ver tienda en vivo](https://wufandmunch.com)

## Funcionalidades

- Catálogo de productos con variantes.
- Carrito de compra y checkout vía Shopify.
- Diseño de marca personalizado (no template genérico de Shopify).
- Preparado para integración de pasarelas de pago adicionales.

## Stack técnico

`HTML5` `CSS3` `JavaScript`


## Estado del proyecto

En producción, tienda activa.
